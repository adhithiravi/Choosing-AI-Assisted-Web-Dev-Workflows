Design notes

States (frame 02)

  • 1 · Saved: 2px primary border, button becomes ✓ In My Agenda (pressed style) with a ghost Remove. Header count updates.
  • 2 · Conflict: attempting to add an overlapping session shows an inline danger message on that card. The message names the conflicting session and its time, and says how to resolve it. The session is not added.
  • 3 · Back-to-back: 11:00 starts exactly when 10:00–11:00 ends. No conflict; normal add button.

Copy

  • Add: “Add to My Agenda” · Saved: “In My Agenda” · Remove: “Remove”
  • Conflict: “Can't add this session. It overlaps with {title} ({time range}) in your agenda. Remove that session first to add this one.”
  • Empty agenda: “Your agenda is empty” / “Add sessions from the schedule to plan your day.”

Accessibility intent

  • Conflict message must be announced to screen readers when it appears.
  • Focus stays on the button that was pressed (blue focus ring shown on card 2).
  • All actions reachable with keyboard. Don't rely on color alone for the saved state: label changes too.

Components

  • Use existing SessionCard and Button from the app library. No new card component.

Not specified here: how overlaps are calculated, where data comes from, persistence. Those are engineering decisions.
