To work with it in Figma, import `index.html` with the html.to.design plugin, or place the PNGs on a page.

## What the design specifies, and what it doesn't

It specifies the visual states (default, saved, conflict, back-to-back), the copy, accessibility intent, and which existing components to use.

It doesn't say how overlaps are calculated, where data comes from, or whether the agenda persists. Those are engineering decisions, and Module 1 is about noticing that gap.
