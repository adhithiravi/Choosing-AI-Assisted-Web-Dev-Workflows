# Lovable prototype (reference copy)

A copy of the kind of prototype Lovable generates from `../lovable-prompt.md`, so you can run and inspect it locally.

```bash
npm install
npm run dev   # http://localhost:8080
```

It's a prototype: it shows the intended add-and-remove flow quickly, but it isn't production code for our app. As you explore it in Module 1, and its code in Module 2, look for:

- what happens when you add two sessions that overlap,
- where the session data comes from,
- which components it uses,
- how it stores and sorts session times,
- what screen reader users hear when a session is added.
